## Useful simplicity principles

- One promise and one action must be clear immediately.
- A real human and strong media create trust faster than long explanation.
- Visitors should move vertically without learning a custom interface.
- Proof should be selected, not dumped as a database.
- Repetition is only useful when it repeats the action after a new persuasion milestone.
- Converted visitors need preparation, not the same pitch again.

## What was not copied

Creator College’s branding, layout, photography, code, typography, current seasonal offer, price stack, urgency, guarantees, bonuses, prizes, FAQ depth, and program mechanics are unrelated to PPC and were not reused.

## Density rule

The homepage must stay under 320 rendered main-content words and at five sections. The automated suite enforces both boundaries so later edits cannot silently rebuild the information-heavy page.
